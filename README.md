# komaec.github.io

Personal homepage. A single static page — `index.html` + `style.css` — served by GitHub Pages (`.nojekyll` disables Jekyll).

- Photo: `images/avatar.jpg`
- Papers and slides: `files/`
- `publications/`, `talks/`, `cv/`, `about/`, `artefacts/` only redirect old URLs to the homepage.

Preview locally: `python3 -m http.server` and open http://localhost:8000.
